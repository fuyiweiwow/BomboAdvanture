# World map open-source references

The civilization-style world map uses an original Godot 4 implementation.
Its axial/offset hex-grid structure and chunk-oriented organization were
informed by the following open-source projects:

- Godot-3D-hex-map by havfo, MIT License:
  https://github.com/havfo/Godot-3D-hex-map
- Unciv, MPL-2.0 License, consulted for 4X map presentation and information
  hierarchy only:
  https://github.com/yairm210/Unciv
- Freeciv-web, AGPL-3.0 License, consulted for 4X map presentation only:
  https://github.com/freeciv/freeciv-web

No source code or visual assets from Unciv or Freeciv are included. Existing
CC0 environment assets and original project code provide the visible content.
