# Controlled random front faces v2

These samples use the original face pixel structure as a seed. Eye geometry (sclera, iris, and lash) is transformed once and mirrored so both eyes keep the same overall size. Pupils remain separate and may differ between sides. Highlights are kept on the left side of each iris; a missing annotated counterpart is filled at the target iris left edge. All transforms are small nearest-neighbor pixel operations; the face base and human ears remain from face_reference_v2.
